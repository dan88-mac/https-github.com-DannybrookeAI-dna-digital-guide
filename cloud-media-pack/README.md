# cloud-media-pack

Staged **project** images, documents, and hidden-folder finds for viewing from GitHub / iPhone Files.

Personal photos/videos are **not** stored here — use `scripts/mac-media-backup-to-icloud.sh` → iCloud Drive. See [MEDIA-CLOUD-IPHONE-METHOD.md](../MEDIA-CLOUD-IPHONE-METHOD.md).

| Subfolder | Purpose |
|-----------|---------|
| `images/` | Logos and brand images |
| `videos/` | Project videos (none yet) |
| `documents/` | Partner PDF packages |
| `hidden-finds/` | Copies found under hidden dirs (e.g. `.pdf-build`) |
| `MANIFEST.md` | File list generated at copy time |
